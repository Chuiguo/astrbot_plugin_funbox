# AstrBot FunBox

安全轻量的群聊趣味工具箱。它会缓存最近群聊上下文，并优先使用 AstrBot 当前 LLM provider 生成趣味回复；LLM 不可用时自动退回规则模板。

v1.1.0 加入“梗档案”：可以把群聊里突然好笑的一句话登记成临时梗，之后用 `/梗词典` 查看、`/梗回收` 复用、`/梗删除` 清掉。梗档案只存在内存里，重启后自然消失。

v1.0.2 加入更多插件配置项：群聊天气、榜单、空间侦探都可以单独开关，群聊天气也可以关闭 LLM 润色来节省 token。

v1.0.1 起，FunBox 加入 `/funbox自检` 和 `/funbox示例`，方便装完以后快速检查配置、复制命令测试。

v1.0.0 起，FunBox 加入 `/群聊天气`：把最近群聊气氛报成赛博天气预报，更适合作为群里随手一玩的入口。

v0.9.0 起，FunBox 加入轻量群聊榜单和隐私控制。可以查看当前缓存状态，也可以随时清掉当前会话样本或让 FunBox 忘记你。

v0.8.0 起，FunBox 加入玩法导航，不需要记住所有命令。可以用 `/趣味菜单`、`/玩点啥`、`/随机玩法` 让它自己带路。

FunBox 会尽量读取 AstrBot 当前会话人格，并优先沿用你给 bot 设置的性格。插件不会额外给自己塞固定人格；配置里的 `persona_style` 只是低优先级口吻提示，可以留空。

机器人昵称，查梗

## 梗档案

```text
/梗诞生 这服务器像猫一样不听话
/梗词典
/梗词典 服务器
/梗回收
/梗回收 服务器
/梗删除 服务器
```

梗档案只保存在当前运行内存里，用来给群聊增加一点连续性，不写数据库，也不会跨重启保留。

## 榜单和隐私

```text
/群聊榜单
/群聊榜单 抽象
/群聊榜单 梗王
/群聊榜单 问号
/funbox状态
/funbox隐私
/funbox清缓存
/funbox忘记我
```

榜单只基于 FunBox 内存里的最近样本，纯节目效果，不代表真实人格。

## 配置项

- `enable_natural_reply`: 是否启用自然语言回复。
- `only_when_addressed`: 是否仅在叫到 bot 名字时自然回复，默认开启，避免乱插嘴。
- `extra_trigger_names`: 额外触发名，例如 `小雪`、`赛博盒子`。
- `max_cache_messages`: 每个会话缓存消息数，默认 90。
- `max_meme_entries`: 每个会话梗档案上限，默认 30，只存在内存。
- `enable_llm`: 是否启用 LLM 上下文生成，关闭后只使用内置模板。
- `persona_style`: 附加口吻提示，可留空；低优先级，不覆盖 AstrBot 当前会话人格。
- `natural_cooldown_seconds`: 未直接叫 bot 名字时的自然回复冷却秒数，默认 180。
- `enable_profiles`: 是否启用群友小档案，默认开启，只基于内存样本。
- `enable_group_weather`: 是否启用群聊天气，默认开启。
- `weather_use_llm`: 群聊天气是否使用 LLM 润色，默认开启；关闭后更省 token。
- `enable_leaderboard`: 是否启用群聊榜单，默认开启。
- `leaderboard_min_samples`: 榜单最低样本数，默认 1；调高可减少偶然上榜。
- `enable_space_detective`: 是否启用空间侦探，默认开启。
- `enable_auto_daily`: 是否启用自动群聊日报，默认关闭。
- `daily_report_hour`: 自动日报小时，默认 23 点。

## 安装

把插件目录放到 AstrBot 插件目录：

```bash
data/plugins/astrbot_plugin_funbox
```

然后重载插件或重启 AstrBot。

## 说明

- 每个会话最多缓存 90 条最近消息。
- 梗档案默认每个会话最多 30 条，只存在内存。
- 群友小档案、群聊日报、梗档案都只使用内存里的最近样本，不写数据库。
- `/funbox隐私` 会说明 FunBox 当前的数据使用方式。
- `/funbox清缓存` 会清理当前会话 FunBox 内存样本，包括梗档案。
- `/funbox忘记我` 只删除当前用户在当前会话里的最近样本，以及这个用户创建的梗。
- 自动日报默认关闭；开启后，到点以后群里有人发言才会触发，每个会话每天最多一次。
- 不额外依赖数据库。
- 不配置 LLM 也能使用兜底模板。
