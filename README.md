# AstrBot FunBox

安全轻量的群聊趣味工具箱。它会缓存最近群聊上下文，并优先使用 AstrBot 当前 LLM provider 生成趣味回复；LLM 不可用时自动退回规则模板。

v2.0.0 是 FunBox 精品版标记：完成群聊速写、菜单帮助、自然触发、兜底回复这一轮打磨。后续继续少加功能，多做质感。

v1.4.4 打磨兜底回复：样本不足、没找到梗、缺少说说原文时，不再像报错，而是给出更自然的等待和补充提示。

v1.4.3 优化自然语言触发：只有把触发名放在开头才算叫到 FunBox，并补全“刚刚群里聊了啥”等速写问法，减少误插嘴。

v1.4.2 精简菜单和帮助文案：默认入口只保留精选玩法，完整命令改为按分类查看，让 FunBox 看起来更像一个有主次的小工具。

v1.4.1 打磨 `/群聊速写`：不再写成小报告，而是压成“标题、画面、镜头、旁白”的四行切片。FunBox 后续走精品路线，少加功能，多打磨体验。

v1.4.0 加入 `/群聊速写`：把最近聊天压成一张短小快照，适合样本还没多到需要日报、但已经有一点群聊味的时候使用。

v1.3.0 加入玩法热度统计和梗档案记忆线。FunBox 会记录哪些玩法真的被用过，以及梗的诞生、回收、删除时间线，让管理面板更像一个群聊文化后台。

v1.2.0 加入 FunBox 管理面板和本地 SQLite 梗档案库。可以在 AstrBot 插件页面里打开面板，查看系统总览、浏览/搜索/删除梗档案、复制常用指令，并按会话清理数据。

v1.1.0 加入“梗档案”：可以把群聊里突然好笑的一句话登记成梗，之后用 `/梗词典` 查看、`/梗回收` 复用、`/梗删除` 清掉。

v1.0.2 加入更多插件配置项：群聊天气、榜单、空间侦探都可以单独开关，群聊天气也可以关闭 LLM 润色来节省 token。

v1.0.1 起，FunBox 加入 `/funbox自检` 和 `/funbox示例`，方便装完以后快速检查配置、复制命令测试。

v1.0.0 起，FunBox 加入 `/群聊天气`：把最近群聊气氛报成赛博天气预报，更适合作为群里随手一玩的入口。

v0.9.0 起，FunBox 加入轻量群聊榜单和隐私控制。可以查看当前缓存状态，也可以随时清掉当前会话样本或让 FunBox 忘记你。

v0.8.0 起，FunBox 加入玩法导航，不需要记住所有命令。可以用 `/趣味菜单`、`/玩点啥`、`/随机玩法` 让它自己带路。

FunBox 会尽量读取 AstrBot 当前会话人格，并优先沿用你给 bot 设置的性格。插件不会额外给自己塞固定人格；配置里的 `persona_style` 只是低优先级口吻提示，可以留空。

## 精选入口

- `/趣味帮助`
- `/趣味菜单`
- `/玩点啥`
- `/群聊速写`
- `/氛围雷达`
- `/名场面`
- `/梗诞生 [内容]`
- `/梗词典 [关键词]`
- `/funbox自检`

完整分类用：

```text
/趣味帮助 常用
/趣味帮助 群聊
/趣味帮助 个人
/趣味帮助 梗档案
/趣味帮助 维护
```

也可以直接叫 bot 昵称自然触发。触发名建议放在开头，例如：

```text
机器人昵称，群里现在什么氛围？
机器人昵称，群聊天气怎么样？
机器人昵称，刚刚有什么名场面？
机器人昵称，刚刚群里聊了啥？
机器人昵称，我今天运势咋样？
机器人昵称，来点好玩的
机器人昵称，你会什么？
机器人昵称，给我看看小档案
机器人昵称，记梗 这服务器像猫一样不听话
机器人昵称，查梗
机器人昵称，回收旧梗
机器人昵称，锐评这条说说
```

普通句子里提到“盒子”不会默认插嘴；如果想让它接话，把 `盒子`、bot 昵称或自定义触发名放在句首。

## 导航

记不住命令时，只用这几个入口：

```text

/玩点啥
/群聊速写

```

## 梗档案

```text
/梗诞生 这服务器像猫一样不听话
/梗词典
/梗词典 服务器
/梗回收
/梗回收 服务器
/梗删除 服务器
```

默认开启 `enable_meme_database` 后，梗档案会写入 FunBox 本地 SQLite，并在插件重新加载时恢复每个会话最近的若干条到内存。最近群聊消息和群友小档案仍只保存在内存里。

## 管理面板

安装后，在 AstrBot WebUI 的插件页面打开 FunBox 页面，可以看到：

- 系统总览：数据库状态、梗档案数量、会话索引、内存样本。
- 梗档案：搜索、按会话筛选、复制 `/梗回收`、删除单条梗。
- 指令库：把常用玩法按入口、梗档案、群聊观察、个人玩法、维护分组。
- 玩法热度：查看哪些 FunBox 玩法被触发最多，以及最近触发记录。
- 记忆线：查看梗的诞生、回收、删除事件流。
- 数据维护：复制自检命令，按会话清理梗档案。

默认不允许面板一键清空全部梗档案。如果确实需要，先在插件配置里开启 `dashboard_allow_clear_all`。

榜单只基于 FunBox 内存里的最近样本，纯节目效果，不代表真实人格。

## 配置项

- `enable_natural_reply`: 是否启用自然语言回复。
- `only_when_addressed`: 是否仅在叫到 bot 名字时自然回复，默认开启，避免乱插嘴。
- `extra_trigger_names`: 额外触发名，例如 `小雪`、`赛博盒子`。
- `max_cache_messages`: 每个会话缓存消息数，默认 90。
- `max_meme_entries`: 每个会话恢复到内存的梗档案上限，默认 30。
- `enable_meme_database`: 是否启用本地 SQLite 梗档案库，默认开启。
- `dashboard_page_limit`: 管理面板默认加载梗档案条数，默认 120。
- `dashboard_allow_clear_all`: 是否允许管理面板清空全部梗档案，默认关闭。
- `enable_usage_stats`: 是否启用玩法热度统计，默认开启。
- `dashboard_timeline_limit`: 管理面板默认加载记忆线事件条数，默认 80。
- `enable_llm`: 是否启用 LLM 上下文生成，关闭后只使用内置模板。
- `persona_style`: 附加口吻提示，可留空；低优先级，不覆盖 AstrBot 当前会话人格。
- `natural_cooldown_seconds`: 未直接叫 bot 名字时的自然回复冷却秒数，默认 180。
- `enable_profiles`: 是否启用群友小档案，默认开启，只基于内存样本。
- `enable_group_weather`: 是否启用群聊天气，默认开启。
- `weather_use_llm`: 群聊天气是否使用 LLM 润色，默认开启；关闭后更省 token。
- `enable_leaderboard`: 是否启用群聊榜单，默认开启。
- `leaderboard_min_samples`: 榜单最低样本数，默认 1；调高可减少偶然上榜。
- `enable_space_detective`: 是否启用空间侦探，默认开启。
- `enable_auto_daily`: 是否启用自动群聊日报，默认关闭。
- `daily_report_hour`: 自动日报小时，默认 23 点。

## 安装

把插件目录放到 AstrBot 插件目录：

```bash
data/plugins/astrbot_plugin_funbox
```

然后重载插件或重启 AstrBot。

## 说明

- 每个会话最多缓存 90 条最近消息。
- 梗档案默认会写入本地 SQLite；每个会话最多恢复 30 条到内存。
- 玩法热度只记录 FunBox 触发命令/自然触发入口，不记录普通聊天内容。
- 梗档案记忆线记录梗诞生、回收、删除事件；清理会话梗档案时会同步清理对应事件。
- 最近消息、群友小档案、群聊速写、群聊日报只使用内存里的最近样本，不写数据库。
- `/funbox隐私` 会说明 FunBox 当前的数据使用方式。
- `/funbox清缓存` 会清理当前会话 FunBox 内存样本，包括梗档案。
- `/funbox忘记我` 只删除当前用户在当前会话里的最近样本，以及这个用户创建的梗。
- 自动日报默认关闭；开启后，到点以后群里有人发言才会触发，每个会话每天最多一次。
- SQLite 使用 Python 标准库，不需要额外安装数据库服务。
- 不配置 LLM 也能使用兜底模板。
