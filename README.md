# AstrBot FunBox

FunBox 是一个安全轻量的 AstrBot 群聊趣味工具箱。它会临时缓存最近群聊上下文，用 AstrBot 当前 LLM provider 生成更有现场感的回复；LLM 不可用时，会自动退回内置规则模板。

当前版本：`v2.1.0`

定位很简单：少堆功能，多打磨已有玩法，让 bot 在群里像一个会接梗、会记梗、但不乱插嘴的小盒子。

## 适合谁

- 想给群聊加一点轻量节目效果。
- 想把群里的经典发言沉淀成梗档案。
- 想要群聊速写、氛围雷达、日报、热词、榜单这类“观察型玩法”。
- 想保留隐私边界：最近消息和小档案只在内存里，梗档案可配置是否落库。

## 快速开始

把插件目录放到 AstrBot 插件目录：

```bash
data/plugins/astrbot_plugin_funbox
```

然后重载插件或重启 AstrBot。

安装后先在群里测试：

```text
/funbox自检
/趣味菜单
/群聊速写
/梗诞生 这服务器像猫一样不听话
/梗词典
```

如果 `/funbox自检` 显示版本、LLM、缓存和配置状态正常，就可以开始使用。

## 常用入口

记不住命令时，只用这几个：

```text
/趣味菜单
/趣味帮助
/玩点啥

```

## 自然触发

FunBox 支持直接叫 bot 昵称触发自然回复。建议把触发名放在句首，这样更准，也不容易误插嘴。

```text
机器人昵称，群里现在什么氛围？
机器人昵称，刚刚群里聊了啥？
机器人昵称，群聊天气怎么样？
机器人昵称，刚刚有什么名场面？
机器人昵称，记梗 这服务器像猫一样不听话
机器人昵称，查梗
机器人昵称，回收旧梗
机器人昵称，锐评这条说说
```

普通句子里顺口提到“盒子”不会默认触发。想让它接话，就把 `盒子`、bot 昵称或配置里的触发名放在开头。

## 玩法地图

### 群聊观察

```text
/群聊速写
/群聊天气
/氛围雷达
/名场面
/群聊热词
/群聊日报
/群聊榜单
```

- `/群聊速写`：把最近聊天压成四行短切片，适合刚聊出一点味道时使用。
- `/群聊天气`：把群聊气氛报成赛博天气。
- `/氛围雷达`：用笑点、问号、感叹号、长消息等信号吐槽群聊空气。
- `/名场面`：捞最近最有节目效果的一句话。
- `/群聊热词`：统计最近反复出现的关键词。
- `/群聊日报`：把热词、名场面和今日气质整理成一份日报。
- `/群聊榜单`：抽象王、梗王、问号王等轻量榜单，纯节目效果。

### 梗档案

```text
/梗诞生 这服务器像猫一样不听话
/梗词典
/梗词典 服务器
/梗回收
/梗回收 服务器
/梗删除 服务器
```

`/梗诞生` 会把一句话登记成群聊梗。开启 `enable_meme_database` 后，梗档案会写入 FunBox 本地 SQLite，并在插件重新加载时恢复每个会话最近的若干条到内存。

`/梗词典` 已升级为轻量梗卡：

```text
梗词典：共 3 条｜最近 3 张梗卡
1. 服务器学｜今日新梗｜未回收
   解释：这句话被群聊空气腌入味了，适合作为临时梗保存。
   出处：这服务器像猫一样不听话
   用法：下次遇到类似场面，可以把它拿出来轻轻回收。
```

带关键词时会展示更完整的搜索梗卡，包括新鲜度、回收热度、出处、解释、用法和收录来源。`/梗回收` 会更新回收次数，让旧梗慢慢长出自己的生命周期。

### 个人玩法

```text
/今日人设
/赛博塔罗
/今日运势
/抽象指数 我是不是有点离谱
/群友小档案
```

这些玩法偏轻量整活。`/群友小档案` 只基于当前会话内存里的最近样本，不写数据库，不代表真实人格。

### 空间玩法

```text
/空间侦探 今天又被生活创飞了
/说说锐评 今天又被生活创飞了
```

用于分析说说、空间动态或类似短文案。输出会尽量保持安全锐评，不攻击本人，不鼓励网暴。

### 维护命令

```text
/funbox自检
/funbox示例
/funbox状态
/funbox隐私
/funbox清缓存
/funbox忘记我
```

- `/funbox自检`：检查版本、LLM、人格、样本、数据库和常用配置。
- `/funbox状态`：查看当前会话缓存和配置状态。
- `/funbox隐私`：说明 FunBox 当前数据使用方式。
- `/funbox清缓存`：清理当前会话 FunBox 内存样本和梗档案。
- `/funbox忘记我`：删除当前用户在当前会话里的最近样本，以及这个用户创建的梗。

## 管理面板

在 AstrBot WebUI 的插件页面打开 FunBox 页面，可以看到：

- 系统总览：数据库状态、梗档案数量、会话索引、内存样本。
- 梗档案：搜索、按会话筛选、复制 `/梗回收`、删除单条梗。
- 指令库：按入口、梗档案、群聊观察、个人玩法、维护分组展示命令。
- 玩法热度：查看哪些 FunBox 玩法被触发最多，以及最近触发记录。
- 记忆线：查看梗的诞生、回收、删除事件流。
- 数据维护：复制自检命令，按会话清理梗档案。

默认不允许面板一键清空全部梗档案。如果确实需要，先在插件配置里开启 `dashboard_allow_clear_all`。

## 配置建议

新手建议保持默认配置，只重点看这几项：

- `enable_natural_reply`: 是否启用自然语言回复。
- `only_when_addressed`: 是否仅在叫到 bot 名字时自然回复，默认开启，建议保持开启。
- `extra_trigger_names`: 额外触发名，例如 `小雪`、`赛博盒子`。
- `enable_llm`: 是否启用 LLM 上下文生成，关闭后只使用内置模板。
- `max_cache_messages`: 每个会话缓存消息数，默认 90。
- `enable_meme_database`: 是否启用本地 SQLite 梗档案库，默认开启。
- `max_meme_entries`: 每个会话恢复到内存的梗档案上限，默认 30。
- `enable_auto_daily`: 是否启用自动群聊日报，默认关闭。

完整配置见 `_conf_schema.json`。

## 数据和隐私

FunBox 的默认边界：

- 最近群聊消息只缓存在内存里，用于速写、天气、雷达、日报、榜单和小档案。
- 群友小档案只基于内存样本，不落库。
- 梗档案默认写入本地 SQLite，用于跨重启保留和管理面板查看。
- 玩法热度只记录 FunBox 玩法触发记录，不记录普通聊天内容。
- 梗档案记忆线记录梗诞生、回收、删除事件。
- `/funbox清缓存` 会清理当前会话 FunBox 内存样本和梗档案。
- `/funbox忘记我` 会删除当前用户在当前会话里的最近样本，以及这个用户创建的梗。

榜单、小档案和梗卡都只是节目效果，不代表真实人格，不适合当成评价群友的依据。

## 常见问题

### 没有 LLM 还能用吗

可以。FunBox 会退回内置规则模板，只是少一些上下文润色。

### 为什么有些群聊观察提示样本不足

群聊速写、日报、天气、雷达等玩法需要最近消息样本。群里再聊几句后再试即可。

### 为什么 bot 没有自然回复

优先检查：

```text
/funbox自检
```

确认 `enable_natural_reply` 已开启，并把 bot 昵称、`盒子` 或自定义触发名放在句首。

### 梗档案会不会一直保存聊天记录

不会。梗档案只保存你用 `/梗诞生` 登记的梗内容。普通最近消息默认只在内存里。

### 自动日报为什么没发

`enable_auto_daily` 默认关闭。开启后，也要等到 `daily_report_hour` 之后群里有人发言，才会触发当天一次自动日报。
