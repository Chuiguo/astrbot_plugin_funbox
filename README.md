# AstrBot FunBox

安全轻量的群聊趣味工具箱。它会缓存最近群聊上下文，并优先使用 AstrBot 当前 LLM provider 生成趣味回复；LLM 不可用时自动退回规则模板。

v0.9.0 开始，FunBox 加入轻量群聊榜单和隐私控制。可以查看当前缓存状态，也可以随时清掉当前会话样本或让 FunBox 忘记你。

v0.8.0 起，FunBox 加入玩法导航，不需要记住所有命令。可以用 `/趣味菜单`、`/玩点啥`、`/随机玩法` 让它自己带路。

FunBox 也会尽量读取 AstrBot 当前会话人格，并把配置里的人格/口吻注入到所有上下文生成里：今日人设、塔罗、日报、空间锐评和自然聊天都会更贴近你给 bot 设置的性格。

## 功能

- `/趣味帮助`
- `/趣味菜单`
- `/玩点啥`
- `/随机玩法`
- `/funbox状态`
- `/funbox清缓存`
- `/funbox忘记我`
- `/群聊榜单`
- `/今日人设`
- `/赛博塔罗`
- `/氛围雷达`
- `/名场面`
- `/今日运势`
- `/抽象指数 [内容]`
- `/群聊热词`
- `/群友小档案 [昵称/QQ]`
- `/群聊日报`
- `/空间侦探 [说说内容]`

也可以直接叫 bot 昵称自然触发，例如：

```text
机器人昵称，群里现在什么氛围？
机器人昵称，刚刚有什么名场面？
机器人昵称，我今天运势咋样？
机器人昵称，来点好玩的
机器人昵称，你会什么？
机器人昵称，给我看看小档案
机器人昵称，锐评这条说说
```

## 导航

记不住命令时，只用这几个入口：

```text
/趣味菜单
/趣味帮助 常用
/趣味帮助 个人
/趣味帮助 群聊
/趣味帮助 空间
/趣味帮助 维护
/玩点啥
/随机玩法
```

## 榜单和隐私

```text
/群聊榜单
/群聊榜单 抽象
/群聊榜单 梗王
/群聊榜单 问号
/funbox状态
/funbox清缓存
/funbox忘记我
```

榜单只基于 FunBox 内存里的最近样本，纯节目效果，不代表真实人格。

## 配置项

- `enable_natural_reply`: 是否启用自然语言回复。
- `only_when_addressed`: 是否仅在叫到 bot 名字时自然回复，默认开启，避免乱插嘴。
- `extra_trigger_names`: 额外触发名，例如 `小雪`、`赛博盒子`。
- `max_cache_messages`: 每个会话缓存消息数，默认 90。
- `enable_llm`: 是否启用 LLM 上下文生成，关闭后只使用内置模板。
- `persona_style`: FunBox 人格/口吻，会注入所有 LLM 生成。
- `natural_cooldown_seconds`: 未直接叫 bot 名字时的自然回复冷却秒数，默认 180。
- `enable_profiles`: 是否启用群友小档案，默认开启，只基于内存样本。
- `enable_auto_daily`: 是否启用自动群聊日报，默认关闭。
- `daily_report_hour`: 自动日报小时，默认 23 点。

## 安装

把插件目录放到 AstrBot 插件目录：

```bash
data/plugins/astrbot_plugin_funbox
```

然后重载插件或重启 AstrBot。

## 说明

- 每个会话最多缓存 90 条最近消息。
- 群友小档案、群聊日报都只使用内存里的最近样本，不写数据库。
- `/funbox清缓存` 会清理当前会话 FunBox 内存样本。
- `/funbox忘记我` 只删除当前用户在当前会话里的最近样本。
- 自动日报默认关闭；开启后，到点以后群里有人发言才会触发，每个会话每天最多一次。
- 不额外依赖数据库。
- 不配置 LLM 也能使用兜底模板。
